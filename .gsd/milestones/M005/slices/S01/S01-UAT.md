# S01: NightShift Naming Cleanup — UAT

**Milestone:** M005
**Written:** 2026-03-16

## UAT Type

- UAT mode: artifact-driven
- Why this mode is sufficient: This slice is a naming/branding rename with no runtime behavior changes. All verification is grep-based string matching plus build/test pass. No live runtime or human-experience testing needed.

## Preconditions

- Repository checked out with S01 changes applied
- Node.js and npm available
- `npm run build` passes (confirms TypeScript compiles)

## Smoke Test

Run `grep -c 'NightShift' src/resources/extensions/gsd/prompts/system.md` — should return ≥1, confirming the core identity prompt says NightShift.

## Test Cases

### 1. Zero GSD branding in prompts

1. Run `rg -w 'GSD' src/resources/extensions/gsd/prompts/`
2. **Expected:** Zero output, exit code 1 (no matches). Every prompt file should say NightShift, not GSD.

### 2. Zero GSD branding in templates and docs

1. Run `rg -w 'GSD' src/resources/extensions/gsd/templates/ src/resources/extensions/gsd/docs/`
2. **Expected:** Zero output, exit code 1. Templates and docs should say NightShift.

### 3. Zero labrat in user-facing surfaces

1. Run `rg -iw 'labrat' README.md examples/ src/resources/extensions/gsd/index.ts`
2. **Expected:** Zero output, exit code 1. No labrat string anywhere in user-facing surfaces.

### 4. README GSD references are only historical/internal

1. Run `rg -nw 'GSD' README.md`
2. **Expected:** Exactly 7 hits. Each must be one of:
   - GitHub repo URL (`gsd-build/GSD-2`)
   - Historical predecessor ("The original GSD...")
   - Internal identifier (`GSD env vars`, `extensions/gsd/`, `GSD-WORKFLOW.md`)
3. No hit should be the product name for the current product.

### 5. ASCII logo says NIGHTSHIFT

1. Run `rg 'LABRAT' src/resources/extensions/gsd/index.ts`
2. **Expected:** Zero output. The old LABRAT logo is gone.
3. Run `rg 'NIGHTSHIFT' src/resources/extensions/gsd/index.ts`
4. **Expected:** At least 1 hit from the ASCII logo block.

### 6. Build passes

1. Run `npm run build`
2. **Expected:** Exit code 0, no TypeScript compilation errors.

### 7. Tests pass

1. Run `npm test`
2. **Expected:** All test suites pass, 0 failures. Specifically check:
   - `prompt-loader.test.ts` — NightShift mention assertion
   - `gitignore.test.ts` — NightShift baseline/preferences assertions
   - `exit-command.test.ts` — "Exit NightShift" assertion
   - `doctor.test.ts` — "# NightShift State" assertion

### 8. Internal identifiers unchanged

1. Run `rg '\.gsd/' src/resources/extensions/gsd/index.ts | grep -i nightshift`
2. **Expected:** Zero output. No `.gsd/` paths were accidentally renamed to nightshift.
3. Run `rg '@gsd/' src/resources/extensions/gsd/index.ts`
4. **Expected:** At least 1 hit — `@gsd/` import paths are preserved.

## Edge Cases

### GSD in code comments and type names

1. Run `rg -w 'GSD' src/resources/extensions/gsd/ --type ts | grep -v 'prompts/' | head -20`
2. **Expected:** Hits are only internal identifiers: type names like `GSDState`, import paths like `@gsd/`, directory refs like `.gsd/`, command refs like `/gsd`. No user-facing string literals saying "GSD" as the product name.

### Examples directory clean

1. Run `rg -w 'GSD' examples/`
2. **Expected:** Zero output. Examples should reference NightShift only.

## Failure Signals

- Any `rg -w 'GSD'` hit in prompts/, templates/, or docs/ = missed rename
- Any `rg -iw 'labrat'` hit in README/examples/index.ts = missed rename
- `npm run build` failure = broken string edit in TypeScript
- `npm test` failure = test assertion not synced with renamed string
- `rg '\.gsd/' ... | grep -i nightshift` returning hits = boundary violation (internal path accidentally renamed)

## Requirements Proved By This UAT

- R042 — NightShift Naming Consistency: all test cases together prove zero user-facing GSD/labrat leaks while preserving internal identifiers

## Not Proven By This UAT

- Runtime behavior of the CLI (no live execution tested — this is a string rename, not a behavior change)
- Whether future prompts generated by S03's scaffold will say NightShift (that's S03's responsibility)

## Notes for Tester

- The 7 README GSD hits in test case 4 are intentional keeps — verify each is genuinely historical/internal, not product branding
- The `gsd` CLI binary name and `/gsd` slash commands are internal identifiers per D077, not branding leaks
